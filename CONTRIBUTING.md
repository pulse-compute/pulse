# Contributing to Pulse

Start with the [contributor workflow](./docs/contributing/README.md) for setup,
focused validation, and pull-request preparation. The
[scope policy](./docs/maintainers/scope-policy.md) owns change classification and
protected-boundary declarations; the [maintainer index](./docs/maintainers/README.md)
points to release and repository operations.

All merges and releases remain human-approved.
