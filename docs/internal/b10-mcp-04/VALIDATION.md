## Failed attempts and environment limits

The initial full unit selection stopped at `report-capsule-contract` after its
30-second timeout (35.92 seconds observed); seven other completed tasks passed.
The isolated retry passed in 27.78 seconds, including 66 negative cases; both
attempts are retained separately in checks.json. No timeout or assertion
was weakened. Initial development failures included stale exact export/catalog
expectations, unsupported AssemblyScript parsing syntax and shared lifecycle
state propagation; corrected focused runs passed. A temporary build-reuse test
switch was removed after the environment catalog check rejected it. The first
manual JavaScript CLI harness run could not resolve the fixture's uninstalled
MCP dependency; linking that declared dependency completed the run.

Node 24.19.0 ran tests and verification; Node 24.18.0 is the pinned context
producer. The 19 existing lockfile-matched dependency directories were reused
from the prior worktree. This is not a fresh dependency installation or
clean-machine acceptance. Pnpm 12.4.2 was resolved through the repository's
pinned toolchain wrapper for real packed consumer checks.

Fastly evidence uses emitted Wasm plus injected provider ABI. Real Viceroy
socket-reset/deadline replays explicitly skipped because `PULSE_VICEROY_BIN`
is absent; no real Fastly service or independent client qualification is claimed.
Full release packing, source-free installed resource acceptance, release seal,
publication and deployment were not performed. Fastly JavaScript support is
not claimed for the new binding. Protected-boundary review and complete CI
qualification remain required before merge.
