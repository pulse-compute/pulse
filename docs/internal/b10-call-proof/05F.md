# 05F — callable failure, cleanup and request budgets

05F (#447) hardens the shared invocation boundary on draft #442. It retains the
existing synchronous language and error owners. There is no catch-and-continue
feature, scheduler, suspension, new allocation limit or Entities primitive emitter.
Public authoring/types remain 05G; real-corpus performance remains 06B.

## Frame lifetime

The ordinary Native generator supplies a private callable cleanup function using
its own value-root inventory and workspace owner. The shared adapter invokes it
at entry and after successful output conversion. It clears local/helper/result
and input handle slots and zeros workspace storage, including on early returns.
This does not reclaim host handles or refund cumulative charges.

A Native exception/trap invalidates the host invocation controller. Supported
start/resume calls then reject; recovery creates a fresh request instance. The
Fastly request likewise runs one instance. No cleanup callback is executed inside
a trapped guest, and diagnostic access to raw exports is not a reusable-instance
contract. Roots in a failed instance are invalidated by disposal of that instance.

JavaScript closes its child execution in `finally`, releases readonly input-copy
fields and clears/releases numeric workspace backing arrays. Escaped views keep
lifetime checks but no live callable workspace. A failed admitted call latches
its error for the request's callable boundary; another call cannot resume it.
Package owners can still frame the original failure. Arbitrary trusted JavaScript
is not sandboxed, and exception syntax remains outside the admitted computation
language. Independent requests receive fresh counters, frames and workspaces.

## Budgets and instrumentation

Native retains the existing cumulative 64 MiB / 1,048,576-value budget and
4,096-page guest memory ceiling. Neither successful cleanup nor a second call
resets these limits. The Node host and injected Fastly fixture retain memory
measurements on failure as well as success; charged bytes, guest linear-memory
capacity and host value handles are separate measurements, not process RSS.

The failure corpus exposed resource-free callable artifacts that omitted Fastly's
shared resource/workspace guards and their request-budget instrumentation. Both
selection conditions now include callable plans. Calls use the existing deadline
owner even when the caller has no resource or workspace declaration of its own.
No-call emission stays conditional and must pass the byte-identical baseline gate.

JavaScript retains its existing request deadline, static-site counts (at most
sixteen), schema bounds, and four workspaces of at most 1,024 numbers per frame.
There is no new JavaScript process-memory accounting promise. Frames release
backing stores between calls; the admitted sixteen-site maximum bounds total
workspace allocation to 512 KiB per request, with at most 32 KiB in an active
frame. Input/output conversion and retained application results are separate.

## Existing error envelopes

Input, computation and output failures must not produce a successful partial
result. Target-specific framing remains with existing owners:

| Boundary | Outcome |
| --- | --- |
| Node Native schema conversion | `PULSE_SCHEMA_ENCODE`; managed JSON input adapter uses `PULSE_SCHEMA_DECODE` |
| Node Native invalid numeric workspace access | `PULSE_NUMERIC_WORKSPACE_INVALID` |
| Node JavaScript Router computation/conversion | HTTP 500 containment |
| Node JavaScript MCP computation/conversion | HTTP 200 MCP result with `isError: true`, no `structuredContent` |
| Injected Fastly Native computation/conversion | Existing provider failure or guest trap; no successful partial response |
| Native allocation exhaustion | `PULSE_RUNTIME_MEMORY_LIMIT_EXCEEDED`; invocation cannot resume |
| Node Router deadline | `PULSE_REQUEST_DEADLINE_EXCEEDED` |
| Fastly Router deadline | HTTP 504 |
| MCP deadline on the three tested targets | HTTP 408 package-owned JSON-RPC interruption error |

The injected Fastly harness is not deployed-provider qualification. Native host
errors are not a promise of identical public HTTP bodies across targets.

## Evidence

`callable-lifetime` compiles real Router and managed MCP source without embedded
resources. It exercises 1/2/16 sequential calls, early returns, repeated requests,
input/computation/output faults, closed-controller rejection, fresh-instance
recovery, shared deadlines and cumulative allocation exhaustion. It retains
artifact hashes and separate memory measurements. The existing JavaScript proof
covers escaped input/resource/workspace/context views, including failure cleanup.

Run the selected task through `wasm/scripts/run-wasm-tests.cjs`; its direct script
accepts a receipt path. Failed development attempts, final checkpoint identity,
no-call baseline comparison and remaining checks are recorded in
[05F-VALIDATION](./05F-VALIDATION.md). Full profiles stay deferred under the user's
checkpoint direction; these are focused development checks, not a release seal.
