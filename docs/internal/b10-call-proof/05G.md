## Public ownership

Runtime owns `PulseComputationContext`, `PulseReadonly`, `PulseComputation` and
`PulseCallSchemas`; Pulse re-exports them. `PulseContext.call` infers the result
from a synchronous computation, takes recursively readonly input at the target,
and returns its independently owned result. The computation context exposes only
resources/workspace. Event contexts do not expose call. Compiler admission still
owns static imported identity, inline literal registered schema IDs, body/placement
restrictions, same-pair identity and the sixteen-occurrence limit.

The canonical API has source-bound schema, computation and HTTP caller examples.
Architecture and runtime docs distinguish this HTTP computation boundary from
one-way event emission. Supported targets remain Node Native, Fastly Native and
explicit Node JavaScript. Fastly JavaScript, factories, runtime registration,
arbitrary package targets, nested/effectful calls and recursion remain excluded.
Existing errors, request budgets and lifetime owners from 05F remain unchanged.

## Versions and diagnostics

Runtime authoring, handler type and context inventories move to v5. The private
frontend is named `canonical-callable.js`; there is no new public factory export.
Callable descriptors and JavaScript binding tables use
`pulse.computation-call.v1`. Native independently validates the descriptor;
JavaScript construction, loading and the shared source-packaging helper reject
stale/unversioned metadata. Native plan and handler-surface format versions stay
unchanged: the optional callable extension owns its own version, retaining
call-free plan identity and byte-equal Wasm.

The CLI catalog owns thirteen source-admission diagnostics and the existing
runtime boundary diagnostic, including summaries, remediations, anchors and exit
policy. Generated diagnostic references, installed docs and the diagnostic-backed
context corpus/resources are regenerated through their canonical owners. Context
resources use pinned Node 24.18.0; they are not manually edited.

## Focused evidence

`callable-public-contract` packs the actual runtime and Pulse packages, checks
exact packed declaration bytes and type-checks positive/negative fixtures through
package exports without workspace aliases. It compiles and executes the canonical
example on all three claimed targets, rejects stale metadata after rehashing,
checks caller positions on Native/JavaScript errors and checks diagnostic metadata.
The task joins the existing Native registry and release evidence shard.
